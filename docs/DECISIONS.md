# Decisions

- **2026-10-13** — No LLM API in the tool. YouTube Data API only; email drafts come from templates filled with real numbers.
- **2026-10-13** — Build on prospect-finder-v5.html, not from scratch.
- **2026-10-13** — First email = one sharp insight from the channel's own data, ~40 words, no pitch. Pitch goes in the reply.
- **2026-10-13** — Weak insights (thin data, small gaps) are flagged "don't send". A so-so insight hurts more than none.
- **2026-10-13** — Thumbnails are judged by Pankaj by eye (top 5 vs latest 5 side by side), not by the tool.
- **2026-10-13** — Runs locally on Pankaj's Mac; keys stay in the browser, never in the repo.
- **2026-10-13** — New work goes in `reach-desk.html`; `prospect-finder-v5.html` stays as the untouched original.
- **2026-10-13** — Per-channel data is cached in the browser for 24h (reopening is free). Video descriptions are stored trimmed to 500 chars; chapters and contacts are worked out from the full text before trimming.
- **2026-10-13** — Shorts = 3 min or under (per spec; v5's search scoring still uses its own 65s rule).
- **2026-10-13** — Key/sheet URL can be remembered in the browser, but only if Pankaj ticks the box (off by default).
- **2026-10-13** — Search is the quota hog (100 units per page; a default run is up to ~3,800 units). The tool shows the cost before each run and warns when it won't fit. No extra API keys/projects to get around the limit (breaks YouTube's terms); if more is ever needed, apply for a quota increase.
- **2026-10-13** — No separate "analyse" step for search leads: search already pulls each channel's uploads, so every kept lead gets insights + drafts for free. The lookup box is only for channels found elsewhere.
- **2026-10-13** — Fair view comparisons: each long video vs the median of up to 4 uploads either side of it ("vs nearby"). Videos under a week old are left out. "Views dropping" needs 2.5x because older videos had more time.
- **2026-10-13** — DMs follow the podcast-dm style: name a/b testing, mention trailer/chapters only when the data shows they're missing, mention edits/AI clips only when Pankaj ticks them, end with a Loom offer. Emails stay insight-only with no pitch (unchanged).
- **2026-10-13** — "Guest name first" is detected by a rule of thumb (capitalised name before a separator, or "with Name"). Example titles are shown on the card so Pankaj can check it before sending.
- **2026-10-13** — Video descriptions are no longer cached (chapters + contacts are worked out first), so far more channels fit in browser storage. Per-lead inputs (name, notes, ticks, chosen insight) are stored separately and never auto-deleted.
- **2026-10-13** — Sending: Google Sheet as the queue + one Apps Script bound to it. Each of the 5 secondary Gmail inboxes installs its own timer and sends as itself. Free, runs with the laptop off. No Instantly/Smartlead for now. Pankaj's main Gmail never sends.
- **2026-10-13** — Inboxes aren't assigned by the tool; the inbox with room claims the next queued lead. Over-selecting is fine, the queue just takes more days.
- **2026-10-13** — Default 4 emails/inbox/day, follow-ups included; weekdays 9–17 in the sheet's time zone; follow-ups on business day 3 and 7 as replies in the same thread; one email per company domain per day; plain text only, no tracking.
- **2026-10-13** — A lead with no host first name waits in the queue (setting `send_without_name` can change this). Bounces and "not interested" replies go to the do-not-email list automatically.
- **2026-10-13** — Apollo: free plan, so emails are pasted into the lead by hand for now. No Apollo API.
