# Decisions

- **2026-10-13** — No LLM API in the tool. YouTube Data API only; email drafts come from templates filled with real numbers.
- **2026-10-13** — Build on prospect-finder-v5.html, not from scratch.
- **2026-10-13** — First email = one sharp insight from the channel's own data, ~40 words, no pitch. Pitch goes in the reply.
- **2026-10-13** — Weak insights (thin data, small gaps) are flagged "don't send". A so-so insight hurts more than none.
- **2026-10-13** — Thumbnails are judged by Pankaj by eye (top 5 vs latest 5 side by side), not by the tool.
- **2026-10-13** — Runs locally on Pankaj's Mac; keys stay in the browser, never in the repo.
- **2026-10-13** — New work goes in `reach-desk.html`; `prospect-finder-v5.html` stays as the untouched original.
- **2026-10-13** — Per-channel data is cached in the browser for 24h (reopening is free). Video descriptions are stored trimmed to 500 chars; chapters and contacts are worked out from the full text before trimming.
- **2026-10-13** — Shorts = 3 min or under (per spec; v5's search scoring still uses its own 65s rule).
